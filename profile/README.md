# EarlyLore

**Product discovery, competitive research & AI idea evaluation before you build.** EarlyLore tracks live software products, website traffic estimates, recorded pricing tiers across 249 niches, computed first-fold Design DNA, and disclosed or payment-verified revenue evidence—keeping the source and observation month next to every fact.

- **Website**: [earlylore.com](https://earlylore.com) · 中文: [earlylore.com/zh](https://earlylore.com/zh)
- **Evaluate an idea**: [earlylore.com/evaluate](https://earlylore.com/evaluate) · [中文](https://earlylore.com/zh/evaluate)
- **MCP Server & Agent Skill**: [earlylore/earlylore-mcp](https://github.com/earlylore/earlylore-mcp) (`https://earlylore.com/api/mcp`)
- **Public docs, method & guides**: [earlylore/docs](https://github.com/earlylore/docs)
- **Explore**: [Products](https://earlylore.com/products) · [Design DNA](https://earlylore.com/design) · [Open-Source / COSS](https://earlylore.com/open-source) · [Research Guides](https://earlylore.com/blog) · [`llms.txt`](https://earlylore.com/llms.txt)
- **Traffic data partner**: [Vaneform](https://vaneform.com)

**EarlyLore 面向独立开发者与 AI 产品团队提供基于真实市场证据的立项评估与竞品研究**：聚合产品流量估算、249 个细分赛道定价基准、首屏 Design DNA 与公开披露收入证据，支持通过托管 MCP 接入 Claude Code / Cursor / Codex / Antigravity。
